# Web (1989 to 1993)

[Português](web.pt-BR.md) · [Brain](../README.md) · Previous: [internet](internet.md) · Next: [social networks](social-networks.md)

**In one sentence:** the web made it almost free to publish to the whole world and to link any document to any other, and it is what took the internet to ordinary people.

## What existed before

The internet already connected computers, but finding information meant knowing which machine held it and how to ask. At CERN, the physics laboratory in Switzerland, thousands of researchers lost information every time someone left.

## The leap

| When | What |
| --- | --- |
| March 1989 | Tim Berners-Lee hands CERN "Information Management: A Proposal", with no name yet for the system |
| end of 1990 | The first system works: server, browser and pages joined by links |
| 30 Apr 1993 | CERN releases the web's protocol and code royalty-free, for anyone to use |
| 1993 | Mosaic comes out, a browser with images inside the text, easy for non-technical people |

## The analysis

- **What became cheap:** publishing. Before, reaching the world took a publisher, a press or a broadcaster. After, a page was enough.
- **The open layer:** HTTP, HTML and each page's address (URL), released at no cost by CERN. The decision not to charge is why the web beat closed systems of the same period.
- **The interface for people:** the browser. The internet was 24 years old when Mosaic let anyone click a link.
- **What it connected:** documents, the way the [Memex](memex.md) imagined: a trail from one text to another.
- **The bad side:** publishing became cheap for everyone, including the false. And links break: linked knowledge also comes undone, because nobody maintains the trails.
