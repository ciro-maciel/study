# Web (1989 a 1993)

[English](web.md) · [Cérebro](../README.pt-BR.md) · Anterior: [internet](internet.pt-BR.md) · Próximo: [redes sociais](social-networks.pt-BR.md)

**Em uma frase:** a web tornou quase gratuito publicar para o mundo inteiro e ligar qualquer documento a qualquer outro, e foi ela que levou a internet às pessoas comuns.

## O que existia antes

A internet já ligava os computadores, mas achar uma informação exigia saber em que máquina ela estava e como pedir. No CERN, o laboratório de física na Suíça, milhares de pesquisadores perdiam informação a cada pessoa que saía.

## O salto

| Quando | O quê |
| --- | --- |
| março de 1989 | Tim Berners-Lee entrega ao CERN a proposta "Information Management: A Proposal", ainda sem nome para o sistema |
| fim de 1990 | Funciona o primeiro sistema: servidor, navegador e páginas ligadas por links |
| 30/4/1993 | O CERN libera o protocolo e o código da web sem cobrar nada, para qualquer um usar |
| 1993 | Sai o Mosaic, navegador com imagens no meio do texto, fácil para quem não é técnico |

## A análise

- **O que ficou barato:** publicar. Antes, chegar ao mundo exigia editora, gráfica ou emissora. Depois, bastava uma página.
- **A camada aberta:** HTTP, HTML e o endereço de cada página (URL), liberados sem custo pelo CERN. A decisão de não cobrar é a razão de a web ter vencido sistemas fechados da mesma época.
- **A interface para as pessoas:** o navegador. A internet tinha 24 anos quando o Mosaic deixou qualquer pessoa clicar num link.
- **O que ligou:** documentos, do jeito que o [Memex](memex.pt-BR.md) imaginou: uma trilha de um texto para outro.
- **O lado ruim:** publicar ficou barato para todos, inclusive para o falso. E os links quebram: o conhecimento ligado também se desliga, porque ninguém mantém as trilhas.
