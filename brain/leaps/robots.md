# Robots (1961 to today, under way)

[Português](robots.pt-BR.md) · [Brain](../README.md) · Previous: [artificial intelligence](ai.md)

**In one sentence:** robots have already made repetitive physical work in a fixed place cheap; the leap still to come is the general-purpose robot, which understands what needs doing anywhere.

## What existed before

Machines provided force, but each made a single movement, designed by someone. The word "robot" came before the thing: it was born in the play R.U.R., by the Czech writer Karel Čapek, which premiered on 2 January 1921.

## The leap, so far

| When | What |
| --- | --- |
| 1921 | The word "robot" premieres on stage |
| 1961 | Unimate, the first industrial robot, starts work on a General Motors assembly line in New Jersey |
| 2002 | Roomba takes a robot into the home, for a single task: vacuuming |
| 2012 | Amazon buys Kiva Systems and puts robots to work moving shelves in its warehouses |

## The analysis

- **What became cheap:** repetitive physical work in a controlled setting: welding, painting, moving boxes along the same path.
- **What has not yet:** varied physical work. Tidying a kitchen it has never seen is still hard for a robot and easy for a child.
- **The open layer:** there is no common layer for robots yet, like TCP/IP or HTML. Each maker has its own way.
- **The interface for people:** it has not arrived. The hypothesis is that it will be the same as AI's: saying what you want, in words.
- **The bad side:** displaced manual work, and the risk of a moving machine making a mistake in the physical world, where mistakes hurt.
