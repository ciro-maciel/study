# Robôs (1961 até hoje, em curso)

[English](robots.md) · [Cérebro](../README.pt-BR.md) · Anterior: [inteligência artificial](ai.pt-BR.md)

**Em uma frase:** os robôs já tornaram barato o trabalho físico repetitivo, num lugar fixo; o salto ainda por vir é o robô de uso geral, que entende o que precisa ser feito em qualquer lugar.

## O que existia antes

Máquinas faziam força, mas cada uma fazia um movimento só, desenhado por alguém. A palavra "robô" veio antes da coisa: nasceu na peça R.U.R., do tcheco Karel Čapek, que estreou em 2/1/1921.

## O salto, até aqui

| Quando | O quê |
| --- | --- |
| 1921 | A palavra "robô" estreia no teatro |
| 1961 | O Unimate, primeiro robô industrial, começa a trabalhar numa linha de montagem da General Motors em Nova Jersey |
| 2002 | O Roomba leva um robô para dentro de casa, para uma tarefa só: aspirar |
| 2012 | A Amazon compra a Kiva Systems e põe robôs para mover prateleiras nos depósitos |

## A análise

- **O que ficou barato:** o trabalho físico repetitivo, em ambiente controlado: soldar, pintar, mover caixas sempre pelo mesmo caminho.
- **O que ainda não ficou:** o trabalho físico variado. Arrumar uma cozinha que nunca viu continua difícil para um robô e fácil para uma criança.
- **A camada aberta:** ainda não existe uma camada comum como o TCP/IP ou o HTML para robôs. Cada fabricante tem o seu jeito.
- **A interface para as pessoas:** ainda não chegou. A hipótese é que seja a mesma da IA: dizer o que se quer, em palavras.
- **O lado ruim:** trabalho manual deslocado, e o risco de uma máquina que se move errar no mundo físico, onde o erro machuca.
